    Manage this project

    The actions below are the typed lifecycle commands that apply to this project right now: adopt, feature, spec, upgrade, plan release, publish, deploy, retire. Each control is rendered from the same execution contract the CLI uses; preview returns a digest and changes nothing; confirming runs the same in-process operation. Only structured fields are accepted — never a shell command or a path you type.
