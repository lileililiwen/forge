# Design: forge-portal-responsive-a11y

## Ownership

Pure CSS (one appended "slice" block in `frontend/styles.css`) plus a
minimal, HTML-free technique for the bulk table. No `frontend/app.js`
edit and no `frontend/index.html` edit are required because the
8-column workspace onboarding rows are generated by
`frontend/app.js:4289` and the column labels are injected from column
position with `td::before { content: … }` + `:nth-child(n)`, so the
dynamic `<td>` cells carry no `data-label` and JS stays untouched.

## Contracts

- **No JS behavior change.** `app.js` rendering of `#ws-rows` (order:
  Onboard, Directory, Project id, Action, Profile signal, State, Id
  override, Profile override — verified at `frontend/app.js:4299-4326`)
  is preserved byte-for-byte; the CSS `:nth-child` labels are pinned to
  that exact order.
- **No API change.** No route, envelope, status code, or body is added,
  removed, or altered.
- **No new capability contract beyond rendering.** The promoted
  `control-plane-portal` delta describes only the responsive +
  reduced-motion *rendering* contract.
- **Keyboard reach + ARIA preserved.** The table region keeps
  `role="region"` + `aria-label="Workspace candidates"` and `tabindex="0"`
  (`frontend/index.html:432`). The `<thead>` is visually hidden via the
  clip technique, not removed, so assistive tech still exposes column
  headers. The checkbox (`input[type=checkbox]`, `aria-label` set in
  `app.js:4296`) and the two override text inputs (`aria-label` set in
  `app.js:4315,4323`) remain in the DOM and focusable inside each
  stacked card. The `>=44px` minima from slice 2 are re-asserted for
  those inputs.

## Failures

- **Mobile reflow must not hide a control.** Each of the eight columns
  is rendered as a labeled flex row inside the card; the Onboard
  checkbox and the Id/Profile override inputs are forced visible
  (`flex:none; width:auto; min-width:120px` for text, `20px` square for
  the checkbox) so they cannot collapse to zero width under the label.
  The verification test asserts all eight `:nth-child` label rules are
  present, which is the observable proxy that no column was dropped.
- **Reduced-motion must not remove function.** The reduced-motion block
  sets `transition:none!important; animation:none!important` only — it
  never sets `display:none`, `visibility:hidden`, or removes content, so
  every control, card, and the rail remain fully operable; only the
  decorative motion is suppressed.
- **Breakpoint layering must not regress earlier steps.** The new
  720px block is appended after the existing 860/850/560/375 blocks and
  deliberately re-declares only `.workbench-grid` (single column) and
  the `#ws-table-wrap` reflow; it does not re-declare `.summary-grid` /
  `.source-list` / `.topbar` padding, so the existing `<=560px` rules
  keep authority there and no cascade conflict is introduced.

## Migrations

None. The change is additive CSS on top of the existing token system
(`--line`, `--panel`, `--muted`, `--text-sm`, slice 2 `min-height:44px`)
and the existing universal reduced-motion guard (`styles.css:23`); no
prior rule is deleted or rewritten.
